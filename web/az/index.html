01 / Sürtünmə

Layihə dəyişəndə hər şey dəyişməlidir.

Developerlər yalnız tapşırıq dəyişmir. Konteksti yenidən qururlar: editor kökləri, terminallar, tətbiq pəncərələri və düzəlişlər. Klyvera bu konteksti birinci dərəcəli obyekt edir.

01

Kontekst əl ilə yenidən qurulur.

Hər layihə eyni qovluq, terminal və pəncərə ritualı ilə başlayır. Masaüstü bunu xatırlamır.

02

Ayarlar dağılır.

Tətbiq seçimləri və düzəliş işarələri yaddaşda və ya səpələnmiş qeydlərdə qalır, layihənin yanında deyil.

03

Etibar gizli qəbul edilir.

İnternetdən yüklənmiş iş məkanı profili aydın təsdiq olmadan əmr işlətməməlidir.

Spaces spesifikasiyasını oxu

Konsept və prototip işi, buraxılmış reliz deyil.

02 / Spaces

Layihə bir məkana çevrilir.

Space layihə yolunu, lazım olan tətbiqləri və istəyə bağlı düzəliş işarələrini saxlayır. Onu açmaq on əməliyyat deyil, bir əməliyyatdır.

  • Layihə yolları açıq qalır. Köklər yoxlanılır; traversal rədd edilir.
  • Tətbiqlər argv massivi kimi açılır. Shell sətri, interpolasiya və ya səssiz icra yoxdur.
  • Düzəliş işarələri Space ilə gedir. Workspace yerləşdirmə skript deyil, məlumatdır.
  • İdxal olunan profillər etibarsız qalır. Əmrlər işləməzdən əvvəl profil hash-i təsdiqlənməlidir.

03 / Shell

Yoldan çəkilən shell.

Launcher, bildirişlər və idarə mərkəzi eyni vizual dili və eyni klaviatura modelini paylaşır. Xətalar uydurma məlumatla əvəz olunmur, görünən qalır.

  • Əvvəlcə klaviatura. Axtar, seç, təsdiqlə və bağla — göstərici olmadan.
  • Dürüst vəziyyətlər. Əlçatmaz xidmətlər uydurma göstərici deyil, deqradasiya vəziyyəti göstərir.
  • Default olaraq lokal. Əsas səthlərə hesab, server və ya şəbəkə lazım deyil.

Launcher

Qeyri-dəqiq tətbiq, Space və ayar axtarışı, son elementlər və tam klaviatura seçimi.

Spaces

Siyahı və detallar, üç addımlı editor, inline yoxlama və açıq etibar təsdiqi.

İdarə mərkəzi

Görünüş, ekran, səs, şəbəkə, Bluetooth, enerji, qısayollar və haqqında bir səthdə.

Ölçülmüş dürüstlük

Xidmət xətaları görünür deqradasiya edir. Status səhifəsi lokal yoxlamaları hədəf işindən ayırır.

04 / Dizayn

Skin deyil, sistem.

Hər rəng, məkan, radius və hərəkət addımı bir token mənbəyindən gəlir. Temalar əl ilə ayrıca boyanmır, həmin mənbədən yaradılır.

  • Temalar

    Tünd, işıqlı və yüksək kontrast uyğun semantik tokenlərlə birinci dərəcəlidir.

  • Kontrast

    Hər temada 47 tələb olunan WCAG AA cütü; lokal hesabatda 0 uğursuzluq.

  • Tipoqrafiya

    Başlıq və UI stack-ləri Manrope və Inter-ə üstünlük verir. Veb şrift yüklənmir.

  • İkonlar

    Klyvera Line, orijinal 1.75 px stroke dəsti. Üçüncü tərəf ikon faylı yoxdur.

  • Hərəkət

    Qısa, funksional keçidlər. Reduced-motion onları söndürür.

tema tokenləri yaradılıb

surface --klyvera-color-surface

05 / Status

Nə realdır, nə sıradadır.

Klyvera prototipdir. Bu xülasə vizyondan qəsdən dardır: burada işləyən işi hələ Arch hədəfi tələb edən işdən ayırır.

Lokal yoxlanılıb

Keçən yoxlamalar

  • Workspace-də 75 Rust testi keçir.
  • 9/9 sxem yoxlaması keçir, o cümlədən etibarsız sənədlər.
  • Hər temada 47/47 tələb olunan WCAG AA cütü keçir.
  • 3 Arch paketi konteynerdə qurulub və smoke-install edilib.
Hədəfdə yoxlanılmayıb

Hələ Arch lazımdır

  • Canlı Hyprland və Quickshell sessiyası.
  • ISO quruluşu, boot, autologin və installer.
  • Asılılıqlarla paket quraşdırılması.
  • GitHub-da CI workflow icrası.
Prototip məhdudiyyətləri

Launch iddiası yoxdur

  • Reliz, imzalanmış paketlər və dəstəklənən installer yoxdur.
  • Məhsul vizualları nümunə məlumatları olan illüstrasiyalardır, canlı sessiya deyil.
  • Lisenziya maintainer təsdiqini gözləyir.
  • Dizaynca heç bir telemetriya yoxdur.
