### Theme API Analysis - Missing Properties

The current Theme.qml (generated by generate.py) is missing approximately 79 properties that QML files still reference:

#### Direct Color Properties (missing from direct access)
QML files use `Theme.accentPurple`, `Theme.danger`, etc. directly, but these are only available in `Theme.palette.colorName`. Need to add direct accessors.

#### Missing Properties
1. **Spacing**: `xxs`, `huge`
2. **Icon sizes**: `icon.sizes.sm`, `icon.sizes.md`, `icon.sizes.lg` (current has flat sizes)
3. **Icon stroke**: `icon.strokeWidth` (current has `icon.stroke`)
4. **Layout properties**:
   - `layout.panel.*`
   - `layout.spaces.*` (sidebarWidth, cardMinWidth, wizardMaxWidth, gridGap)
   - `layout.launcher.*`
   - `layout.controlCenter.*`
5. **Motion**: `motionDuration` function (should be `motion.duration`), also `durationFast/Normal/Slow` as direct properties
6. **Borders**: `borders.focus`, `borders.strong`
7. **Typography families**: `uiFamily`, `headingFamily`, `monoFamily`
8. **Typography scale**: `display`, `bodyStrong`, `caption`, `heading1`, `heading3`
9. **Accessibility**: `focusRingOffset`

#### Files Using Missing Properties
- shell/ui/WorkspaceIndicator.qml: spacing.xxs, accentPurple, textSecondary, borderStrong, motionDuration, surfaceActive, surfaceHover, focusRing
- shell/ui/SystemIndicators.qml: textDisabled, danger, onAccent, typography.uiFamily, typography.caption
- shell/ui/Toast.qml: layout.spaces.cardMinWidth, borders.focus, icon.sizes.md, typography.uiFamily, typography.body, typography.caption
- shell/ui/ListItem.qml: layout.spaces.sidebarWidth, accessibility.preferredTargetSize, icon.sizes.md, typography.bodyStrong, typography.caption, borders.focus, selection
- shell/pages/Welcome.qml: background, typography.headingFamily, typography.heading3, typography.display, typography.heading1
- preview/main.qml: surfaceSunken, typography.headingFamily, typography.display, typography.uiFamily, typography.monoFamily, typography.body, typography.caption, layout.spaces.gridGap, accentMint
- preview/pages.qml: layout.spaces.wizardMaxWidth, overlay, layout.controlCenter.widthWide, layout.controlCenter.widthRegular
